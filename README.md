# Telecom_Labs

Репозиторий содержит лабораторные работы по курсу **«Телекоммуникации»**, посвящённые основам цифровой обработки сигналов. Каждая работа оформлена в виде Jupyter Notebook и сопровождается пояснениями, визуализациями и практическими примерами.

## 📚 Содержание

- `lucher_lab01.ipynb` — **Звуки и сигналы**  
- `lucher_lab02.ipynb` — **Гармоники**  
- `lucher_lab03.ipynb` — **Апериодические сигналы**  
- `lucher_lab04.ipynb` — **Шум**  
- `lucher_lab05.ipynb` — **Автокорреляция**  
- `lucher_lab06.ipynb` — **Дискретное косинусное преобразование**  
- `lucher_lab07.ipynb` — **Дискретное преобразование Фурье**  
- `lucher_lab08.ipynb` — **Фильтрация и свёртка**  
- `lucher_lab09.ipynb` — **Дифференцирование и интегрирование**  
- `lucher_lab10.ipynb` — **Сигналы и системы**  
- `lucher_lab11.ipynb` — **Модуляция и сэмплинг**

### Дополнительно

- `thinkdsp.py` — Вспомогательные функции для анализа сигналов  
- `csv/` — Наборы данных  
- `audio/` — Аудиофайлы, используемые в лабораторных
